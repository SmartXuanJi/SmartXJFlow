TRIGGERS

八种触发方式，把流程放到该跑的地方

同一个流程既能守着键盘按 F5，也能在你下班后自己跑完；每种入口都有对应的人机边界——需要人确认的步骤不会被悄悄跳过。

▶️

手动运行

编辑器内 F5，可选运行模式、回退策略与步骤延迟，进度与日志实时可见。

F5 · 运行模式 · 步骤延迟
⏰

定时调度

间隔 / 每天 / 每周 / 每月，未来 7 天触发预览；失败重试、连续失败自动停用、错过执行提醒，配置时校验交互节点并给替换建议。

cron 预览 · 重试 · 无人值守
📑

批量运行

导入 CSV / XLSX，自动列映射，逐行执行并汇总成表；失败行单独重跑，不重复消耗额度，批次结果可归档重开。

CSV/XLSX · 只重跑失败 · 批次归档
📂

文件夹监听

新文件落到目录就开跑：文件名通配 + 稳定时长防抖，按路径 / 大小 / 修改时间去重，成功可移动或保留，失败留原地可重试。

通配 · 防抖 · 去重 · 默认关闭
🔗

API 触发

本地 HTTP 服务提供运行、查询、OpenAPI 与健康检查；每个流程独立 Token（只存摘要、明文仅显示一次），带限流与调用统计。

POST /api/v1/run · 127.0.0.1
🗂️

轻量表单

按流程输入声明自动生成自包含 HTML 表单，支持文本、选项、文件与目录；提交后轮询显示进度与结果，不用装客户端。

自包含表单 · 异步轮询
🏗️

子流程

一条流程里调用另一条已保存流程，支持输入映射与指定输出节点，并阻断循环引用——把常用片段沉淀成可复用组件。

subflow · 输入映射 · 防循环
🧪

不落库试跑

模板与引导页的「直接跑给我看」：完整执行但不写执行记录、步骤与检查点，也不计预算，新用户 30 秒就能看到一次真实输出。

零副作用 · 不计预算
