免费版能跑到哪一步：10 个节点的真实边界

与其猜"免费版是不是试用版"，不如把边界一次列清楚：能干什么、什么时候才需要付费。下面按应用内版本对比页的真实口径写，额度以「账户与授权」为准。

免费版（登录后）真的有这些

治理与稳定性（不是试用） - 运行前体检：结构、变量引用、必填配置、凭据缺失、危险 SQL / 高危代码分级 - 一键修复：确定性无损项直接修；空模型、缺接口、缺输入给可点的修复按钮 - 环境一键体检：AI 接口连通性、本地模型、定时任务、流程结构 - 失败自愈、零配置引导、简易模式、命令面板 / 统一搜索

执行能力 - 批量运行、文件夹监听、断点续跑 - 定时任务 1 个、API 触发 1 个流程、MCP 客户端 1 个 Server、A2A 智能体接入 1 个 - 单流程 ≤10 个节点、单 AI 接口 - 模板集市与模板一键跑通：子集

专业版才有这些

  • 节点与编排：全部节点类型、无限节点、子流程、数据库连接、调试（单步/断点）、Code 扩展库
  • AI 生成闭环：分阶段生成（全部节点）、沙盒预检、样例数据真实试跑、AI 修复生成、AI 助手语音与多步编排
  • 知识与模型：知识库检索、经验库与记忆注入、本地模型（GGUF/向量）、本地语音（STT/TTS）、图片生成、视频生成
  • 对外与协作：MCP 工具出口、A2A 出口、轻量表单、通知渠道（Webhook / 企微 / 钉钉 / 飞书）、团队模板目录、只读分享链接、模板集市全部、云同步
  • 合规与导出：审计证据包、操作审计日志、高级导出（Word / Excel / PDF）、策略层模型路由与策略包分发、API Key 安全设置
  • 额度：定时任务与 API 触发不限、多 AI 接口、MCP / A2A 不限

什么时候该付费：四个信号

  1. 你已经在同一条流程上跑到 10 个节点 的限制（说明它不是玩具流程）；
  2. 你需要每天自动跑（1 个定时任务不够），或需要多个 AI 接口做对比/降级；
  3. 你要把结果交给别人（审计摘要包、Word/Excel/PDF 导出、Webhook 推送到群）；
  4. 你需要本地模型或知识库（数据不能出本机，或回答必须基于自己的文档）。

反过来，如果你只是"把一批表格筛一遍、写个新文件"，免费版就够，不必为了"看起来很专业"先付费。

三个必须说清的边界

  • 不是"全功能免费"：上面列出的专业版能力在免费版里是灰态，不是限次试用；
  • 额度与功能位以应用内为准：版本更新后可能调整，本文写的是 v2027.1.0 的口径；
  • 买断 ≠ 永久更新：买断只覆盖当前版本的问题修复；需要持续更新选订阅。

建议的验证顺序

先装免费版跑通一条自己真实的流程 → 记下卡在哪一步（节点数？定时？导出格式？知识库？）→ 再看对应能力是不是专业版 → 用 ¥0.9 体验 3 天验证 → 确认能省事再买。这样最不容易后悔。
